## 项目介绍

**Art Engine** 是一个基于 **Java 21 + Spring Boot 3.x** 构建的现代化后台基础引擎项目，致力于提供一套 **高性能、可扩展、易维护** 的通用管理后台基础能力。

项目在架构设计上遵循 **模块化、组件化、低耦合** 的原则，内置了完整的 **权限体系、数据权限、规则引擎、缓存支持**
，可作为企业级项目的基础框架或二次开发底座。
